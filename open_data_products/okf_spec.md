# Open Knowledge Format v0.1 Adapter

The SDK treats OKF as an external Markdown knowledge-bundle format for agent
context, import, and export workflows.

Canonical specification:
https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md

The SDK does not treat OKF as part of the Open Data Products standards family.
ODPS, ODPC, ODPG, and ODPV remain the canonical structured artifacts.
